# Docker Basics

Docker is a containerization platform that allows applications
and their dependencies to be packaged into containers.

## Docker Image

A Docker image is a read-only template used to create containers.

## Docker Container

A container is a running instance of a Docker image.

## Dockerfile

A Dockerfile contains instructions used to build a Docker image.

## Docker Volume

Docker volumes are used to persist data generated by containers.

## Docker Network

Docker networks allow containers to communicate with each other.
